## 项目概览

论文处理 Agent 是一个面向学术研究流程的自动化工具。项目将论文格式转换、内容整理、结构化卡片生成和后续研究材料组织拆分为多个可复用模块。

## 核心内容

- 论文文件格式转换脚本
- 多个面向具体任务的 skill
- 可复用的论文处理工作流
- 结构化论文卡片和验证步骤
- GitHub 版本管理与项目文档

## 我的工作

- 独立设计并组织 Agent 的目录结构、技能边界和执行流程。
- 编写格式转换脚本，降低论文材料进入后续处理流程的人工成本。
- 将复杂研究任务拆分为可复用、可验证的 skill。
- 编写项目文档，说明输入、处理步骤、输出和限制。

## 项目价值

这个项目体现了我把自然语言研究需求转化为自动化工作流的能力，也体现了我对脚本开发、模块化设计、文档化和结果验证的重视。
