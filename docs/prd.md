# PRD：SSpongEE 个人网站

## 目标访问者

主要访问者是课程教师、助教、同学，以及未来查看我项目记录的人。他们最先寻找的信息是：我是谁、学习方向是什么、这个网站是否属于我本人、项目和联系方式是否真实可访问。

## 希望访问者记住什么

我叫 SSpongEE，我的定位是“我什么都能学”，方向是金融与技术。我希望通过这个网站展示自己能够用 AI Agent、GitHub 和规范化文档完成一个可验证的个人网站项目。

## 本期必须包含

- Hero：公开称呼、个人定位和清晰入口。
- About：真实个人简介和金融与技术方向。
- Skills：金融学习、技术工具、AI 协作和项目表达能力。
- Projects：至少一个项目卡片，当前展示本课程个人网站项目。
- Contact：至少提供 GitHub 主页链接，并可选展示邮箱。
- README、Design、Checklist、Final Report 和关键截图。
- GitHub Pages 正式链接。

## 本期明确不做

- 不做登录、数据库、支付、后台管理或访客追踪。
- 不公开课程邀请码、密码、API Key、Token、私人住址等敏感信息。
- 不追求复杂动画、博客系统、论文系统或无关高级功能。
- 不保留模板作者的个人信息、示例项目或虚构经历作为成品内容。

## 完成标准

- GitHub Pages 链接可以在无痕窗口访问。
- 首页五个基础区块内容真实、可读、无明显占位文字。
- 桌面端和手机端主要内容显示正常。
- GitHub 链接、邮箱链接和项目入口可以点击。
- `docs/checklist.md` 中的项目都有证据支持。
- `report/final-report.md` 写明过程、AI 参与、个人判断、验证结果和后续计划。
- TA-Claw 预览无误，并完成二次确认提交。

## 不能公开的信息

课程邀请码、作业代码、个人密码、API Key、Token、`.env` 文件、身份证件、私人住址、私人反馈和其他不适合公开的个人信息。
