# Checklist：SSpongEE 个人网站验收清单

完成每一项后，需要用截图、链接、文件路径或复现步骤作为证据。

## 内容检查

- [ ] 首页显示 SSpongEE 和定位“我什么都能学”。
- [ ] About 内容是本人真实学习方向，没有模板作者信息。
- [ ] Skills 至少包含金融学习、技术工具、AI 协作和项目表达。
- [ ] Projects 至少有一个项目，且项目状态标注真实。
- [ ] Contact 至少包含有效 GitHub 链接。

## 功能检查

- [ ] 导航可以进入 Projects 页面。

- [ ] 页面没有明显 404、死链或错误跳转。

## 显示检查

- [ ] 桌面端首页文字、头像和链接显示正常。
- [ ] 手机端首页主要内容可读，没有横向溢出。

- [ ] `README.md` 已写明模板来源、主要修改、Pages 链接和隐私说明。

- [ ] 仓库不包含 `.env` 文件。
