# Design：SSpongEE 个人网站

## 页面区块与浏览顺序

首页按照从快速识别到深入了解的顺序组织：

1. Hero：显示 SSpongEE、个人定位“我什么都能学”和金融与技术方向。
2. About：说明网站用途、学习兴趣和个人方向。
3. Skills：列出金融学习、技术工具、AI 协作和项目表达能力。
4. Projects：引导访问者查看课程个人网站项目。
5. Contact：提供 GitHub 和邮箱联系方式。

Projects 页面只展示与本作业相关的项目，避免让模板示例内容干扰验收。

## 颜色、字体与整体风格

保留 al-folio 的简洁学术风格和响应式布局。整体视觉以清爽、可读、专业为主，不额外添加复杂动画或高风险样式。当前阶段优先保证内容真实、导航清楚和移动端可读。

## 桌面端和移动端要求

- 桌面端：首页文字和头像区域不重叠，导航可点击。
- 手机端：内容按单列阅读，头像、文字、项目卡片不溢出。
- 链接在桌面端和手机端都应可点击。
- 截图需要覆盖桌面端首页和手机端首页。

## 关键文件职责

- `_config.yml`：站点名称、姓名、描述、语言、发布 URL 和全局功能设置。
- `_pages/about.md`：首页内容，包括 Hero、About、Skills、Projects 和 Contact。
- `_pages/projects.md`：项目列表页。
- `_projects/1_project.md`：本课程个人网站项目详情。
- `_data/socials.yml`：公开邮箱和 GitHub 等社交链接。
- `README.md`：项目说明、模板来源、修改内容、运行方式、Pages 链接和隐私说明。
- `docs/prd.md`：需求和边界。
- `docs/checklist.md`：可验证验收清单。
- `report/final-report.md`：最终报告。
- `screenshots/`：提交证据截图。

## 保留与修改

保留：

- al-folio 的 Jekyll 结构。
- 响应式布局和 GitHub Pages 自动部署方式。
- 简洁学术型视觉风格。

修改：

- 替换模板作者信息和示例文本。
- 关闭暂不需要的示例导航。
- 将项目内容改为本课程作业。
- 补齐作业要求的文档和证据目录。

## 图片和外部素材

当前首页不展示个人头像，避免继续使用模板自带人物图片造成占位内容误判。如果后续替换为个人图片，必须确认图片可以公开展示，不包含隐私信息，并在报告中说明来源。
